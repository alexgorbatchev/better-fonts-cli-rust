Use `better-fonts help [COMMAND...]` to query any documented command path. The generated help tree accepts the following query paths; each takes a variadic command path and the global options documented in commands.md.

- `better-fonts app help`
- `better-fonts app help help`
- `better-fonts app help list`
- `better-fonts app help patch`
- `better-fonts app help status`
- `better-fonts app help unpatch`
- `better-fonts completion help`
- `better-fonts completion help help`
- `better-fonts completion help script`
- `better-fonts config help`
- `better-fonts config help help`
- `better-fonts config help init`
- `better-fonts config help path`
- `better-fonts config help show`
- `better-fonts help app`
- `better-fonts help app list`
- `better-fonts help app patch`
- `better-fonts help app status`
- `better-fonts help app unpatch`
- `better-fonts help completion`
- `better-fonts help completion script`
- `better-fonts help config`
- `better-fonts help config init`
- `better-fonts help config path`
- `better-fonts help config show`
- `better-fonts help help`
- `better-fonts help self`
- `better-fonts help self upgrade`
- `better-fonts help skill`
- `better-fonts self help`
- `better-fonts self help help`
- `better-fonts self help upgrade`
